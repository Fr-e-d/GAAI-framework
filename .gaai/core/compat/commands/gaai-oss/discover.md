# /gaai-oss:discover

Activate the GAAI OSS Discovery Agent to clarify intent and produce governed artefacts.

## Instructions for Claude Code

Read `.gaai/core/agents/discovery.agent.md`.

Ask the human to describe their intent if not already provided. Then follow the Discovery workflow: plan, create artefacts, validate, and hand off to Delivery if ready.

At the end, confirm what was added or changed in the governed backlog.
